Detection and Recognition Settings

1 = SAM3 on every processed frame. N = SAM3, then N−1 KCF frames. Lost tracking triggers early detection. Camera frames skipped while busy are not counted.


SAM3 accepts 1–4 comma-separated class names (for example: medicine bottle, medicine box). Text features are computed when the prompt changes. References must pass the DINOv3 threshold. The class of the eligible reference with the highest Lab similarity wins; no eligible references means unknown.
